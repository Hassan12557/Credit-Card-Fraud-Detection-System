# Credit Card Fraud Detection System

## Problem
Detect fraudulent transactions in highly imbalanced financial data.

## Objective
Maximize fraud detection (recall) while minimizing false positives.

## Dataset
- **Samples:** 284,807 | **Features:** 30 | **Fraud rate:** 0.17% (492 frauds)
- **Features:** V1–V28 (PCA-transformed), Time, Amount, Class
- **Missing values:** None | **Imbalance ratio:** 1:578
